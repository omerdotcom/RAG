## ✨ Features

- **100% Local & Private** — Runs entirely on your hardware using Ollama
- **High-quality embeddings** with `nomic-embed-text`
- **Smart chunking** with recursive text splitter (optimized for documents)
- **Persistent vector store** (Chroma) — ingest once, query forever
- **Strong system prompt** for reduced hallucinations
- **Streaming-ready** architecture (easy to enable)
- **Clean LCEL chains** (LangChain Expression Language)
- **Easy to extend** — hybrid search, reranking, evaluation, web UI

### Performance Highlights
- Fast retrieval on consumer hardware (RTX 4060 / M2 / M3)
- Good accuracy on technical PDFs, research papers, and personal notes
- Built with best practices from 2026 local RAG systems
